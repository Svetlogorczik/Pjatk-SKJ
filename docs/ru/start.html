Как читать этот сайт#

Как читать пометки

  • 📘 материал основан на лекции / материалах занятий
  • ✍️ от автора дополнение автора сайта (объяснение, пример, совет) — этого нет в материалах
  • 🔁 переделанное задание — та же логика, что на занятиях, но другой текст и другой код
  • Лекции (W1–W8) — весь материал лекций, объяснённый простым языком, с примерами и формулами.
  • Ćwiczenia (C1–C7) — задания с занятий, переделанные так, что логика та же, а текст и код другие (ты не копируешь работы прошлых лет).
  • Коллоквиум и Проект — что нужно уметь и как готовиться.
  • Кнопка 📝 Конспект в каждой теме открывает короткую шпаргалку «по шагам». Все сразу (для печати) — на странице Все конспекты.
  • Кнопка ✓ Отметить как пройденное сохраняет прогресс в твоём браузере (полоска в меню).
  • У каждого блока кода есть Копировать, у файлов — Скачать.
  • Справа вверху: язык (PL / EN / RU) и тема (светлая / тёмная).
💡ПодсказкаДля русскоязычных студентов в Польше ✍️ от автора

Предмет идёт на польском, поэтому в тексте рядом с русскими терминами часто стоят польские и английские. Удобная шпаргалка «PL ↔ EN ↔ RU» — в Словаре. Переключайся на PL, когда готовишься к ответам на занятиях.

Предлагаемый порядок учёбы#

  1. Прочитай Сдача предмета и даты — чтобы понимать, на что всё влияет.
  2. Подготовь компьютер (ниже).
  3. Лекции W1 → W8 — после каждой открой Конспект и ответь на «Проверь себя».
  4. Ćwiczenia C1 → C7 — запускай каждую программу, а не только читай.
  5. Коллоквиум — тренировка с сервером DrillServer.
  6. Проект — по этапам, от 150 баллов и выше.

Установка Java (JDK)#

Нужен JDK (а не только JRE) — в нём есть компилятор javac.

  1. Установи JDK (например, Eclipse Temurin / OpenJDK). Версия 8, 11, 17 или 21 — подойдёт любая, но код пиши совместимым с Java 8 (ниже).
  2. Проверь в терминале: java -version и javac -version.
  3. Если javac «не является командой» — добавь папку bin из JDK в переменную PATH (Windows: Переменные среды).

Несколько программ сразу#

Сетевые программы почти всегда запускают в нескольких терминалах (сервер + клиент, несколько узлов).

Совместимость с Java 8#

Проект должен быть на Java 8. Эти конструкции новее — не используй их:

Не используйС версииВместо этого (Java 8)
var x = ...10явный тип: String x = ...
List.of(...), Map.of(...)9Arrays.asList(...), new HashMap<>() + put
"ab".repeat(3)11цикл / StringBuilder
str.isBlank(), strip()11trim().isEmpty(), trim()
list.getFirst(), getLast()21list.get(0), list.get(list.size() - 1)
текстовые блоки """..."""15обычные строки с \n
record, switch со стрелками14–16класс, классический switch с break

javac --release 8 сразу покажет такие ошибки, даже если у тебя более новый JDK.

Wireshark#

  1. Скачай Wireshark с сайта проекта и установи. На Windows отметь установку Npcap (с поддержкой loopback, чтобы видеть localhost).
  2. На Linux добавь пользователя в группу wireshark (или запускай через sudo).
  3. После запуска выбери интерфейс: Wi-Fi / Ethernet для Интернета, Loopback / lo для программ на localhost.
  4. Старт (синий плавник) → сделай что-то в сети → Стоп (красный квадрат) → введи фильтр, например http.
