How to read the markers

  • 📘 content based on the lecture / class materials
  • ✍️ author's note added by the site author (explanation, example, advice) — not in the materials
  • 🔁 rewritten task — same logic as in class, but different wording and code

What you will find here#

  • 8 lecture topics (chapter 1 of Kurose & Ross) — with analogies, KaTeX formulas and "Check yourself" questions.
  • 7 labs — HTTP, DNS and TCP in Wireshark plus programs with TCP/UDP sockets. All code is tested and Java 8 compatible.
  • Practical test — our own training server with 5 task types and a model solution.
  • Project — requirements, scoring, a plan for building the proxy, traps of the provided programs, test scripts and a documentation template.
  • Course rules & dates — what is known from the materials and what you need to ask your instructor.

Unofficial study notes. The tasks were rewritten (different wording, same logic) so that nothing from previous years is copied.
