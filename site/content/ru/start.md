## Установка Java (JDK)

Нужен **JDK** (а не только JRE) — в нём есть компилятор `javac`.

:::steps
1. Установи JDK (например, Eclipse Temurin / OpenJDK). Версия 8, 11, 17 или 21 — подойдёт любая, но код пиши совместимым с **Java 8** (ниже).
2. Проверь в терминале: `java -version` и `javac -version`.
3. Если `javac` «не является командой» — добавь папку `bin` из JDK в переменную `PATH` (Windows: *Переменные среды*).
:::

### Компиляция и запуск из терминала

```bash
cd papka-s-failami
javac MiniWebServer.java          # появится MiniWebServer.class
java MiniWebServer 8080           # запускаешь КЛАСС (без .class), аргументы через пробел
javac *.java                      # все файлы сразу (так преподаватель компилирует проект!)
javac --release 8 *.java          # проверка совместимости кода с Java 8
```

### Несколько программ сразу

Сетевые программы почти всегда запускают **в нескольких терминалах** (сервер + клиент, несколько узлов).

| Система | Как открыть ещё одно окно |
|---|---|
| Windows | новое окно `cmd`/PowerShell или в скрипте `.bat`: `start "имя" cmd /k java Program` |
| Linux / macOS | новая вкладка терминала или в скрипте: `java Program &` (в фоне) |
| IntelliJ | несколько конфигураций запуска; **Run → Edit Configurations → Program arguments** для аргументов; опция *Allow multiple instances* |

## Совместимость с Java 8

Проект должен быть на **Java 8**. Эти конструкции **новее** — не используй их:

| Не используй | С версии | Вместо этого (Java 8) |
|---|---|---|
| `var x = ...` | 10 | явный тип: `String x = ...` |
| `List.of(...)`, `Map.of(...)` | 9 | `Arrays.asList(...)`, `new HashMap<>()` + `put` |
| `"ab".repeat(3)` | 11 | цикл / `StringBuilder` |
| `str.isBlank()`, `strip()` | 11 | `trim().isEmpty()`, `trim()` |
| `list.getFirst()`, `getLast()` | 21 | `list.get(0)`, `list.get(list.size() - 1)` |
| текстовые блоки `"""..."""` | 15 | обычные строки с `\n` |
| `record`, `switch` со стрелками | 14–16 | класс, классический `switch` с `break` |

`javac --release 8` сразу покажет такие ошибки, даже если у тебя более новый JDK.

## Wireshark

:::steps
1. Скачай Wireshark с сайта проекта и установи. На **Windows** отметь установку **Npcap** (с поддержкой **loopback**, чтобы видеть `localhost`).
2. На **Linux** добавь пользователя в группу `wireshark` (или запускай через `sudo`).
3. После запуска выбери интерфейс: **Wi-Fi / Ethernet** для Интернета, **Loopback / lo** для программ на `localhost`.
4. Старт (синий плавник) → сделай что-то в сети → Стоп (красный квадрат) → введи фильтр, например `http`.
:::

## Полезные консольные инструменты

| Инструмент | Для чего | Пример |
|---|---|---|
| `ping` | отвечает ли хост, RTT | `ping pjwstk.edu.pl` |
| `tracert` / `traceroute` | маршрут через роутеры | `tracert pjwstk.edu.pl` |
| `nslookup` | DNS-запросы | `nslookup -type=MX pjwstk.edu.pl` |
| `curl -v` | HTTP-запрос с заголовками | `curl -v http://localhost:8080/` |
| `nc` / `telnet` | «ручной» разговор по TCP | `nc -C localhost 5050` |
| `netstat` / `ss` / `lsof` | кто занял порт | `netstat -ano \| findstr 8080` |
| `ipconfig` / `ip a` | мой IP-адрес | `ipconfig /all` |

:::tip Брандмауэр
При первом запуске сервера Windows может спросить доступ к сети для Java — разреши для **частных сетей**. Если тестируешь только на `localhost`, брандмауэр обычно не мешает.
:::
